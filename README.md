# NumPy & Pandas Practice Assignment

This repository contains my practice work on **NumPy and Pandas**, covering array operations, Series manipulation, and DataFrame exploration and manipulation.

## Topics Covered

### NumPy

* Creating 1D and 2D NumPy arrays
* Inspecting array shape, data type, and number of elements
* Celsius to Fahrenheit conversion
* Finding maximum, minimum, and mean values
* Array indexing and slicing
* Extracting specific days and weeks from temperature data
* Working with 2D arrays

### Pandas Series

* Creating Pandas Series with custom index labels
* Indexing and slicing
* Using `loc` and `iloc`
* Boolean filtering
* Modifying Series values
* Removing entries
* Performing calculations on Series

### Pandas DataFrame

* Creating DataFrames from structured data
* Exploring DataFrames using:

  * `head()`
  * `tail()`
  * `shape`
  * `columns`
  * `dtypes`
  * `info()`
* Selecting specific columns
* Using `iloc` for column slicing
* Filtering rows using conditions
* Finding value counts and unique values
* Grouping data and calculating mean values
* Modifying existing values
* Creating new calculated columns
* Removing rows and columns

## Tools & Libraries

* Python
* NumPy
* Pandas
* Jupyter Notebook

## Dataset

The exercises use small, practice-oriented datasets covering:

* Weekly temperature observations
* Student marks and ranks
* Product transactions across different categories and regions

## Purpose

The purpose of this assignment was to build a practical understanding of **NumPy arrays, Pandas Series, and Pandas DataFrames**, with a focus on indexing, slicing, filtering, aggregation, and basic data manipulation.
